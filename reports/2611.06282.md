### 一句话总结

MonoLaDN 通过训练期的语言引导去噪，将 VLM 基于图像与真实框生成的几何推理迁移到单目 3D 检测器，在不增加推理成本的情况下将 KITTI Car test Moderate $AP_{3D|R40}$ 从 MonoDGP 的 18.72 提升至 20.45，但跨域证据仅限 KITTI→nuScenes 的深度误差，尚未验证跨域检测 AP。

### 问题与动机

单目 3D 检测需要从单张 RGB 图像恢复目标深度、尺寸和朝向，本身存在几何歧义；远距离、遮挡和截断会进一步削弱视觉线索。MonoDETR、MonoDGP 等检测器主要依赖图像与 3D 框监督，缺少显式的高层语义和空间先验。

VLM 具有较丰富的语义知识，但直接部署为检测器的计算成本较高，且其精确 3D 几何能力仍有限。论文因此采用训练期知识迁移：先将真实几何转换为离散语言标签，再让冻结 VLM 解释可见证据，通过辅助去噪任务影响检测器的共享表示，部署时删除语言分支。

这里需要区分：**VLM 并非独立估计真实几何，而是在已知真实几何标签的条件下生成解释**。因此，核心问题还包括：这类解释是否比直接使用标签或模板文本提供了额外监督价值。

### 方法要点

- **以 MonoDGP 为视觉检测主干。** 使用 ResNet-50、多尺度视觉特征及深度引导 decoder；训练时增加辅助推理 queries，推理时只保留原有检测路径。

- **离线生成目标级、属性级推理。** 为每个真实目标构造 full image、clean crop 和背景变暗的 object-attended view。将真实标注映射为 occlusion、depth、dimension、angle 四类离散标签，再由冻结 VLM 为每个标签生成一句视觉证据解释。最终使用 SpaceThinker-Qwen2.5-VL-3B。

- **在文本 embedding 空间构造去噪任务。** 用 SigLIP 编码四类推理，经两层 MLP 预测对角 Gaussian 的 $\mu,\sigma$，采样 $q_P=\mu+\sigma\odot\epsilon$ 作为推理 queries。这里是语言表示扰动，**不修改输入图像的外观或目标细节**。

- **用非对称 attention mask 控制信息流。** Leakage Prevention Mask 禁止检测 queries 读取来自真实标注的推理 queries，避免训练期捷径；Separated Reasoning Mask 允许推理 query 读取同一目标的全部属性、其他目标的同类属性以及检测 queries。知识迁移依靠共享网络的训练，而非部署时读取语言信息。

- **联合重建文本表示与目标几何。** $\mathcal{L}_{emb}$ 包含 cosine reconstruction loss 和 Gaussian 到标准正态分布的 KL 正则，固定 $\beta=4.0$；$\mathcal{L}_{obj}$ 重建目标的 2D/3D 几何。occlusion 表示作为共享可见性上下文参与 depth、dimension、angle 重建。辅助分支与检测损失共同训练，部署时全部移除。

### 实验

**数据与设置。** KITTI 包含 7481 张训练图像和 7518 张测试图像，训练集进一步划分为 3712 张训练图像、3769 张验证图像。指标为按 40 个 recall positions 计算的 $AP_{3D|R40}$ 和 $AP_{BEV|R40}$，区分 Easy、Moderate、Hard。跨域实验使用 KITTI 训练的模型，在 nuScenes frontal validation 的 Car 类上零微调评估 depth MAE。

模型使用 AdamW、batch size 8，在单张 NVIDIA RTX 3090 上训练 250 epochs。主要比较包括 MonoDGP、MonoDLGD、MonoCLUE、MonoDETR，以及使用额外 LiDAR 或 Depth 监督的 OccupancyM3D、OPA-3D 等。

**KITTI Car 主要结果。** 以下三元组均按 Easy / Moderate / Hard 排列。

|---|---|---|---|---|
| MonoDGP | 26.35 / 18.72 / 15.97 | 35.24 / 25.23 / 22.02 | 30.76 / 22.34 / 19.02 | 39.40 / 28.20 / 24.42 |
| MonoDLGD | 29.11 / 19.87 / 17.74 | 36.63 / 25.30 / 23.13 | 34.89 / 25.19 / 21.78 | 41.68 / 30.53 / 27.76 |
| MonoCLUE | 27.94 / 19.70 / 16.69 | 36.15 / 26.15 / 22.81 | 33.74 / 24.10 / 20.58 | 41.79 / 29.91 / 26.00 |

MonoLaDN 在所列 test 指标中领先，但 val Moderate、Hard $AP_{3D|R40}$ 仍低于 MonoDLGD，不能概括为所有设置均最优。

**跨域深度误差。** 下表为 nuScenes frontal validation 的 depth MAE，越低越好。

| 方法 | 0–20 | 20–40 | 40–$\infty$ | All |
|---|---:|---:|---:|---:|
| GUPNet | 0.82 | 1.70 | 6.20 | 1.45 |
| DEVIANT | 0.76 | **1.60** | **4.50** | **1.26** |
| MonoCon | 0.78 | 1.65 | 6.02 | 1.40 |
| MonoUNI | 0.72 | 1.79 | 4.98 | 1.43 |
| MonoCD | 0.73 | 1.59 | 5.78 | 1.33 |
| MonoLaDN | **0.55** | 1.62 | 4.76 | 1.28 |

MonoLaDN 在近距离最优，远距离及 All 为第二；20–40 区间落后于 MonoCD 和 DEVIANT。因此正文“各区间最低或次低”的说法与表格并不完全一致。表中没有 MonoDGP，无法直接确认语言分支对跨域深度误差的增益。

**消融结论。** 下列为 KITTI val Car Moderate $AP_{3D|R40}$；除特别注明外，相关方法比较使用 Qwen2.5-VL-7B 生成推理。

| 对比项 | 设置与结果 |
|---|---|
| 基线与 embedding 重建 | MonoDGP：22.34；加入推理分支、CLIP 与 $\mathcal{L}_{emb}$：22.55 |
| Text encoder | CLIP：22.55；SigLIP：22.72 |
| 重建目标 | 仅 $\mathcal{L}_{emb}$：22.72；仅 $\mathcal{L}_{obj}$：23.15；两者联合：23.61 |
| Separated Reasoning Mask | 不使用：23.61；使用：24.52 |
| VLM 选择 | Qwen2.5-VL-7B：24.52；InternVL3.5-8B：24.83；SpaceThinker-3B：25.03 |
| 防泄漏约束 | 无 mask：10.92；仅 Leakage Prevention Mask：23.61 |
| 扰动位置 | BBox perturbation：22.83；Reasoning perturbation：23.69；Embedding perturbation：24.52 |

这些结果支持：几何重建比单独文本匹配更有效，两类目标互补；防泄漏约束至关重要；同一目标不同属性之间保留交互优于完全隔离。VLM 对比也说明，参数规模并非决定因素，空间推理专门训练可能更有价值。

**其他类别与成本。** KITTI test 上，MonoLaDN 的 Pedestrian 和 Cyclist $AP_{3D|R40}$ 分别为 16.57 / 10.81 / 9.03 和 6.64 / 4.45 / 3.42，在所列方法中领先。
