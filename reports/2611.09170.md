### 一句话总结

FIND 针对 LiDAR 3D Detection 的 Test-Time Adaptation（TTA），通过可学习 B-Spline 图频域滤波和双流一致性学习分离稳定几何与域特定扰动，在两项跨数据集任务上相对 MOS 平均提升 +2.27 AP_BEV、+3.24 AP_3D，但依赖目标域在线更新，并非严格的 single-domain generalization。

### 问题与动机

LiDAR 检测器容易受到传感器线束配置、采样模式、地点和天气变化的影响。论文关注 Fully TTA：保留源模型训练方式，在测试阶段利用无标签目标数据更新模型；部署后不访问源样本，但初始化滤波器时需要预先计算源域频谱统计量。

现有方法主要在空间域施加扰动、生成伪标签或聚合历史模型。作者认为，稀疏、不规则点云中的语义几何与传感器噪声相互纠缠，空间域一致性容易同时保留域偏差。

论文用三项频谱观察支撑设计：

- **域差异遍布全频段。** 不能简单把高频当作噪声；去除低频会损坏整体形状，抑制中频会造成碎裂，去除高频会丢失车轮等细节。
- **相邻频段的域差异波动明显。** 固定频带切分和全局多项式滤波难以精细处理。
- **域内不稳定性与跨域差异正相关。** 频谱能量的 Coefficient of Variation（CV）与跨域 KL divergence 呈正 Spearman correlation，因此可用目标域自身的统计量间接指导滤波；给定正文未列出相关系数具体数值。

### 方法要点

- **在预测目标框内构建语义图。** 对框内点云中心化，通过 kNN 和 Gaussian kernel 构图，对 normalized Graph Laplacian 分解，使用 Graph Fourier Transform（GFT）表示几何频谱。对象级处理减少背景干扰，但也使方法依赖初始检测框质量。

- **用 B-Spline 实现局部频谱调节。** 将频谱范围划分为若干 bins，学习频段端点响应，再通过固定线性映射求得 B-Spline 系数。默认设置为 \(N=12\)、\(K=3\)，利用基函数的局部支撑调节窄频段，避免硬切频带。

- **Invariant Stream 用滤波结果选择原始点。** 初始响应根据源域频谱 CV 构造，稳定频段保留更多。在线阶段比较滤波后与原始点的坐标范数比例，再通过动态阈值选择点；检测器实际接收的是这些点的**原始坐标**，而非直接接收滤波后坐标。这有助于减少坐标变形，但仍可能删除关键细节。

- **Specific Stream 学习抵抗频谱扰动。** 提取 \(X_{\mathrm{sp}}\)，构造 \(X+\epsilon_rX_{\mathrm{sp}}\)，其中 \(\epsilon_r\) 从 \((-1,1)\) 采样；以 Invariant Stream 输出作为伪标签，用源检测损失约束 Specific Stream。其作用类似数据驱动的几何扰动增强。

- **用在线稳定性和互补约束联合优化。** 累积目标数据的频谱能量一、二阶矩，以 CV 构造 stability mask，鼓励两个滤波器分别关注稳定和不稳定频段；再约束 \(h_{\mathrm{in}}+h_{\mathrm{sp}}\approx1\)，避免共同退化。总目标由 consistency、stability 和 complementarity 三项组成，后两项默认权重为 \(0.8\)、\(0.6\)。

### 实验

**设置与基线。** 主检测器为 SECOND-IoU，batch size 为 8，优化器设置沿用 MOS。数据集包括 nuScenes、Waymo、KITTI 和 KITTI-C；主要基线为 Tent、CoTTA、Reg-TTA3D、MOS、DUO，另比较 SC-NNK、L-TTA、SPA。

**跨数据集检测。** 下表为 Car、moderate difficulty 的 AP_BEV / AP_3D。

| 方法 | nuScenes → KITTI | Waymo → KITTI |
|---|---:|---:|
| Source | 45.50 / 13.78 | 65.64 / 26.74 |
| Oracle | 83.29 / 73.45 | 83.29 / 73.45 |
| Tent | 45.13 / 19.33 | 68.54 / 34.57 |
| CoTTA | 68.81 / 47.61 | 67.46 / 35.34 |
| Reg-TTA3D | 70.21 / 49.32 | 81.60 / 61.03 |
| MOS | 71.13 / 51.11 | 81.90 / 64.16 |
| DUO | 69.85 / 50.08 | 75.38 / 62.39 |
| FIND | **75.21 / 54.66** | **82.35 / 67.09** |

相对 MOS，两个任务的 AP_3D 分别提升 +3.55、+2.93。Waymo → KITTI 的 AP_BEV 接近 Oracle，但 AP_3D 仍有差距；nuScenes → KITTI 的 AP_3D 距 Oracle 更远，因此不宜把“接近全监督性能”推广到所有场景与指标。

**腐败鲁棒性。** 下表为 Car、moderate detection difficulty 的平均 AP_3D；easy、moderate、heavy 指腐败强度。

| 方法 | KITTI-C easy | KITTI-C moderate | KITTI-C heavy | Waymo → KITTI-C heavy |
|---|---:|---:|---:|---:|
| Source | 70.91 | 58.56 | 54.95 | 14.41 |
| MOS | 74.16 | 61.82 | 57.48 | 32.62 |
| DUO | 74.08 | 61.36 | 56.96 | 31.14 |
| FIND | **74.81** | **62.69** | **59.62** | **33.99** |

FIND 在 KITTI-C heavy 上相对 MOS 平均提升 +2.14 AP_3D；Incomplete echoes（Inc.）从 Source 的 27.49 提升至 38.49。复合偏移 Waymo → KITTI-C 上，相对 Source 提升 +19.58，但平均 AP_3D 仍只有 33.99，说明复杂偏移尚未解决。FIND 也并非逐项最优，例如 KITTI-C heavy 的 Rain 为 78.23，低于 DUO 的 78.49。

**关键消融。** 下表均报告 Car 的 AP_3D。

| 配置 | nuScenes → KITTI | Waymo → KITTI |
|---|---:|---:|
| 仅 consistency | 48.81 | 58.93 |
| 仅 stability | 35.87 | 43.91 |
| stability + complementarity | 49.76 | 60.62 |
| consistency + stability | 52.49 | 64.48 |
| 完整 FIND | **54.66** | **67.09** |
| Rigid filter | 32.56 | 39.10 |
| Global polynomial filter | 48.38 | 50.21 |

消融支持三个结论：一致性与稳定性指导互补；complementarity 能进一步改善结果；局部 B-Spline 明显优于所比较的 Rigid 和 Global filter。超参数实验表明 bins 太少会欠分辨、太多会振荡，高阶 B-Spline 会扩大支撑范围；具体曲线数值文中未说明。

**持续适应与失败信号。** Fog → Rain → Snow 无重置测试中，FIND 平均 AP_3D 从独立适应的 71.46 降至 71.09；MOS 从 69.87 降至 68.83。预测框扰动中，移除 10% 的框影响最大：Waymo → KITTI-C 上 FIND 降至 32.39，低于 MOS 的 32.62。多类别实验中，FIND 在九项结果中取得七项最佳，但 Waymo → nuScenes 的 Pedestrian、Cyclist 分别为 1.99、4.35，均低于 Reg-TTA3D 的 2.23、4.73。

**计算开销。** 单张 NVIDIA RTX 4090、batch size 8，时间为每点云平均处理时间，显存为适应阶段峰值分配量。

| 方法 | Time (ms) | Memory (MiB) |
|---|---:|---:|
| CoTTA | 179 ± 10 | 10,462 |

FIND 比 MOS 快，但慢于 DUO，显存也更高。其 spectral filtering 占 13.92%，dual-stream adaptation 占 45.36%；进一步优化时不能只关注特征分解。

### 与你研究的关系

**与跨域鲁棒检测和语义保持增强高度相关，与严格 single-domain generalization 的设定有明显距离。** FIND 在测试时持续利用目标域数据更新模型与滤波器，不能直接作为“只用单一源域训练、部署后冻结”的 DG 方法比较。

最值得借鉴的是以下设计：

- **不要预设某个频段只包含风格。** 论文关于全频段语义与域因素纠缠的观察，可启发图像风格增强：验证不同频段对语义、边缘和小目标的影响，再决定如何调节，而非固定移除高频。
- **将“保留语义”和“施加扰动”拆成两个视图。** 一路产生较可靠监督，另一路承受可控域扰动，这与风格增强下保持检测一致性的需求直接相关。迁移到源域训练阶段、形成冻结部署的 DG 方法，是值得验证的方向，论文未做该实验。
- **用原始点选择减少几何变形。** Invariant Stream 不直接使用重建坐标，体现了对几何保持的考虑；但点删除是否损伤远距离小目标，仍需额外评估。

### 局限与可追问点

- **“稳定”是否等于“域不变”？** CV 与跨域 KL divergence 的相关性支持启发式设计，但不能证明因果关系。类别比例、距离、目标尺度和点数变化也可能改变频谱统计；值得在固定类别、距离和密度后重新验证。

- **梯度路径需要核实。** Invariant Stream 使用硬指示函数选择点，常规梯度无法通过离散选择传回滤波响应。正文同时声称联合优化，但未说明是否采用梯度近似，以及 consistency 对 Invariant filter 的实际更新路径。

- **滤波响应约束不够清楚。** 初始化响应位于 \([0,1]\)，正文未说明在线优化如何保证端点和连续响应始终有界。stability loss 对响应是线性的，需要核实是否存在负响应、B-Spline 插值过冲及相应约束。

- **依赖初始框，可能形成错误反馈。** 现有扰动仅覆盖有限幅度的位置误差及 10% 漏检、误检；严重漏检下的自我强化、类别偏差和失败恢复机制仍不明确。

- **小目标与边界框保持证据不足。** 有 Pedestrian、Cyclist 结果，但没有按目标距离、点数、尺寸或遮挡程度分组，也没有点删除率、框尺寸偏移或细节保留指标；定性可视化不能充分证明语义保持。

- **长期分布变化验证仍有限。** 在线频谱统计采用历史累积平均，可能被旧域主导；目前持续适应仅测试 Fog → Rain → Snow。可进一步测试反复切换、长序列、混合传感器以及滑动窗口统计。

- **消融尚不能完全隔离机制。** B-Spline 与 Global filter 的参数容量、初始化和优化条件是否充分匹配，文中未说明；源域 CV 初始化相对随机初始化或纯目标统计初始化的贡献也缺少独立结果。

- **部署和复现边界。** 作者承认谱变换开销及密度变化下的超参数调节问题。还需明确最终预测取自哪个 stream、两流参数共享或更新方式、伪标签停止梯度策略，以及当前 batch 是更新前还是更新后计分；这些细节会影响 TTA 公平比较与复现。
