### 一句话总结

Stylus 将 facial stylization 建模为预训练 diffusion model 中的局部几何修正，通过 latent 插值与 self-attention query 优化，在无需额外训练的条件下取得较强的身份和内容保持能力，但风格指标并非全面最优，且尚未验证其对跨域目标检测的实际收益。

### 问题与动机

论文研究参考图像驱动的人脸风格迁移：输出既要具有明显的艺术风格，又要保留原人物身份、面部结构和内容细节。

作者指出，现有 diffusion-based 方法容易在风格强度与身份保持之间失衡；基于文本指令的 Qwen-Image-Edit、FLUX.2-dev 则难以精确描述参考图像中的视觉风格，也缺乏连续调节风格强度的机制。StyleID 使用 content query 与 style key/value 注入风格，能保持结构，但可能限制风格表达。

论文的核心动机是：原始 latent 或 query 空间中的线性插值，没有考虑这些变量经过模型映射后的非线性变化，因此可能产生重影、身份漂移或较弱的风格迁移。Stylus 从线性插值出发，在模型隐藏表示中降低加权距离，对插值点做小幅修正。其理论解释限于**局部 pullback geometry**，并不保证找到完整 content–style 路径上的全局最优 geodesic。

### 方法要点

- **用隐藏表示定义几何。** 正文将冻结 U-Net 的 down-path/bottleneck 映射定义为 \(g\)，以 \(G=J_g^\top J_g\) 构造 pullback metric。在 \(J_g\) 局部满列秩的假设下，latent 中的曲线长度可对应到隐藏表示流形上的曲线长度；该假设是否在实际优化区域成立，文中未验证。

- **修正 content–style latent 插值。** 先构造 \(x_m=\delta x_c+(1-\delta)x_s\)，再最小化
  \[
  E=\alpha\left[\delta\|g(x_m)-g(x_c)\|^2+(1-\delta)\|g(x_s)-g(x_m)\|^2\right].
  \]
  这相当于让映射后的中间点接近加权目标，而非直接求解整条 geodesic。较大的 \(\delta\) 使初始化更接近 content。

- **用 rank-one approximation 降低优化成本。** 通过自动微分计算 Jacobian-vector product 和 vector-Jacobian product，并对 \(J_g^\top J_g\) 做 power iteration，仅保留主要奇异方向来近似梯度，不显式构造完整 Jacobian。优化最多进行 10 次，能量变化低于 \(10^{-4}\) 时提前停止。

- **在 self-attention query 中再次修正插值。** 从 \(Q_m=(1-\beta)Q_c+\beta Q_s\) 出发，以 attention module \(f\) 的输出距离构造类似能量并优化 query；key/value 来自 style 图像且保持固定。\(\beta\) 控制风格注入强度。附录说明该优化施加于每个 transformer block 的第一层 self-attention，覆盖相应空间分辨率及全部 50 个 DDIM steps。

- **双层控制无需额外训练。** latent 修正控制整体混合，query 修正补充细节与风格注入。默认参数为 \(\delta=0.9\)、\(\alpha=5\)、\(\beta=0.25\)，sampling steps 为 50，guidance scale 为 3.0。

### 实验

**数据与协议。** 从 CelebA 随机选取 20 张 content 图像，从 WikiArt-Face 和 MetFace 各选取 40 张 style reference。WikiArt-Face 进行带 0.5 expansion ratio 的人脸裁剪，并调整至 \(512\times512\)；MetFace 不做额外预处理。具体配对方式、重复随机采样次数及置信区间，文中未说明。

**基线与指标。** 对比 AesPA-Net、ArtFlow、CAST、StyTR2、InST、DiffStyle、DiffuseIT、StyleID、Qwen-Image-Edit、FLUX.2-dev；StyleSSP 与增加同类 ControlNet、IP-Adapter 的 Stylus* 单独比较。指标为 ArtFID↓、LPIPS↓、ID↓、CS↑，其中 ID 是 normalized ArcFace embeddings 点积的一减值。

下表摘录主要结果，数字来自 Table 1：

| Style 数据集 | 方法 | ArtFID↓ | LPIPS↓ | ID↓ | CS↑ |
|---|---|---:|---:|---:|---:|
| WikiArt | ArtFlow | 22.9778 | 0.4933 | 0.2555 | 0.3215 |
| WikiArt | StyTR2 | 24.2880 | 0.4068 | 0.1760 | 0.5181 |
| WikiArt | StyleID | 24.0963 | 0.3785 | 0.1618 | 0.4493 |
| WikiArt | Stylus | 24.4906 | **0.2616** | **0.1237** | **0.5531** |
| MetFace | StyTR2 | 26.6994 | 0.4104 | 0.1599 | 0.5503 |
| MetFace | StyleID | 26.6917 | 0.5283 | 0.1646 | 0.4283 |
| MetFace | Stylus | **26.6203** | **0.3118** | **0.1424** | **0.5618** |
| MetFace，额外控制 | StyleSSP | 35.6287 | **0.4079** | 0.1658 | **0.5322** |
| MetFace，额外控制 | Stylus* | **31.2170** | 0.5228 | **0.1441** | 0.4454 |

**主要结论。** 不增加额外控制时，Stylus 在两个风格数据集上的 LPIPS、ID、CS 均优于 Table 1 中的其他方法；MetFace 的 ArtFID 也最好。但 WikiArt 上，ArtFlow、StyleID 和 StyTR2 的 ArtFID 都优于 Stylus，因此正文所称“third-place WikiArt ArtFID”与表格不符。增加额外控制后，MetFace 上 Stylus* 与 StyleSSP 各有优势，不能概括为全面领先。

**组件消融。** 以下结果使用 MetFace 作为 style reference：

| 配置 | ArtFID↓ | LPIPS↓ | ID↓ | CS↑ |
|---|---:|---:|---:|---:|
| w/o Sty. Interp. Init. | 26.4807 | 0.3647 | **0.1250** | 0.4933 |
| w/o Sty. Inject Ctrl | **26.3421** | 0.3861 | 0.1470 | 0.4735 |
| w/o both | 26.7091 | 0.3877 | 0.1473 | 0.4715 |
| Stylus | 26.6203 | **0.3118** | 0.1424 | **0.5618** |

完整模型主要改善 LPIPS 和 CS；移除 latent 插值初始化反而得到更低的 ID，移除任一组件也可能改善 ArtFID。这说明两组件存在实际的内容、身份与风格权衡，不能解读为所有指标同步改善。

**机制与泛化分析。**

- 调节 \(\beta\) 可产生逐渐增强的风格效果，但 ArtFID 并非始终改善；默认 \(\beta=0.25\) 是经验折中。
- 路径曲率诊断显示，energy-refined trajectory 比随机扰动更平滑，同时偏离直线；它不证明 intrinsic curvature、有界曲率或全局 geodesic 最优性。
- SD v1.5、v2.0、v2.1 上相对 StyleID 的内容与身份保持优势总体持续；MetFace 的 SD v1.5 设置下，StyleID 的 ArtFID 更好。
- MS-COCO 物体和复杂场景、WikiArt art-to-art 的扩展仅提供定性展示，未报告检测指标或系统性结构保持评估。

**计算成本。** 单张 \(512\times512\) 图像在 NVIDIA H800 上的 inference time 为：

| 方法 | Inference Time (s) |
|---|---:|
| StyleID | 3.97 |
| StyleSSP | 6.56 |
| Stylus | 9.71 |
| DiffStyle | 68.24 |
| DiffuseIT | 226.82 |

Stylus 无需额外训练，但比 StyleID 和 StyleSSP 慢。显存占用及普通消费级 GPU 的运行表现，文中未说明。

- **面向单源域数据构造可控风格增强。** \(\delta\)、\(\beta\) 提供连续调节入口，可用于研究增强强度与跨域检测性能之间的关系。若严格遵循 single-domain generalization，应明确 style reference 的来源及外部数据使用边界，避免依赖未知目标域样本。

- **借鉴局部几何诊断。** 可以将其与线性插值、StyleID 式注入进行比较，进一步检验几何修正是否确实减少对象位移、边界模糊和小目标消失，并把这些变化与目标域检测性能关联起来。

复现吸引力目前有限：没有公开实现，报告硬件为 H800，而且每张图像包含多层、多个 sampling step 的梯度优化；是否适合大规模检测数据增强仍需测量。

### 局限与可追问点

- **正文与附录对 \(g\) 的定义冲突。** 正文明确采用 down-path/bottleneck hidden-state map，并强调不是最终 noise prediction；Appendix H.1 却称 \(g\) 是完整 U-Net noise predictor，且通过 \(g_u\circ g_d\) 求导。这会改变能量、Jacobian、维度假设和计算成本，是复现前最需要澄清的问题。

- **“geodesic”解释强于已展示的保证。** 实际算法优化单个加权中间点，并截断为主要 Jacobian 方向；\(J_g^\top r\) 是映射空间损失对应的坐标梯度，不能直接等同于 pullback metric 下的 Riemannian gradient。现有结果支持局部修正有效，但尚不能将收益唯一归因于 geodesic navigation。

- **rank-one approximation 的证据不完整。** 正文提到 Appendix D 的 top-\(k\) 对比，但给定内容未包含其数字。需要补充不同 rank、完整 vector-Jacobian product、power iteration 次数及随机初始化的质量与耗时对比，并区分 power iteration 与外层优化的迭代预算。

- **存在其他报告口径问题。** CS 在正文称为 Content Loss，却按 CS↑ 报告，具体公式未说明；附录计算成本部分称 DiffuseIT、InjectFusion 需要风格专属训练，与同文的基线说明及 Training Required 表格冲突，不能据此接受相关训练成本优势。

- **缺少任务相关失败案例。** 给定内容展示了线性插值的重影、模糊等问题，但没有系统报告 Stylus 自身在遮挡、多实例、极端风格和小目标上的失败率。对检测应用，应优先验证 bounding box 是否仍有效，以及风格图像中的结构是否会被错误注入。

- **规模、效率与真实域偏移仍待验证。** 主要定量实验只使用 20 张 content 人脸，没有置信区间；非人脸结果主要为定性展示。值得进一步追问：在等计算预算、等风格强度下，它是否优于简单风格增强？艺术风格下的内容保持，能否转化为真实未知目标域上的检测收益？
