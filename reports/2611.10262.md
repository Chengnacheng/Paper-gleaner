### 一句话总结

论文提出面向单一源域目标检测的 Origin-Anchored Multi-Style Consistency（OAMSC），通过人工核验的多风格生成数据、同场景分组训练和 Origin EMA teacher 特征对齐提升未知域泛化，在天气与 simulation-to-real 迁移上表现突出，但跨相机性能未超过 GDD，且主要收益来自数据覆盖和分组训练，层级一致性的增益较小。

### 问题与动机

论文研究 source-only Domain Generalization：训练仅使用有标注的源域数据，不访问目标域数据，要求检测器适应未知的相机、天气、仿真到现实和图像损坏偏移。

作者认为，现有检测器容易依赖纹理、颜色等外观统计线索；有限的源域风格使这种捷径学习在未知域失效。现有增强与一致性方法还有两个不足：

- 手工设计的扰动集合覆盖有限，难以充分模拟真实外观变化。
- 原图与增强图之间缺少可靠的场景、实例对应关系；增强伪影或不稳定的对齐参考可能污染一致性监督。

OAMSC 的出发点是：**先构造保持目标与标注一致的跨风格视图，再利用明确的同场景、同实例对应关系学习风格不变特征**。这也使生成质量成为整套方法成立的前提。

### 方法要点

- **离线构建 Label-Preserving Multi-Style 数据库。** 使用商业 Seedream 3.0、4.0、4.5 和 5.0 Lite，将 Cityscapes 和 RealDriveSim 转换为 20 种风格，涵盖 Painting and Fine Art、Anime and Comics、Film and Games、Materials and Crafts。共生成 179,471 张变体，不含 Origin。每张变体都与 Origin 人工比对；目标缺失、重复、位移、变形或标注不匹配会触发重新生成与检查，合格图像继承原始框和类别。

- **按场景组织训练，而非独立随机抽取图像。** 每组包含一个 Origin 和三个风格视图，风格跨 epoch 重采样，并尽可能来自不同风格家族。组内共享几何变换及框变换，保证一致性比较针对外观差异；所有视图都接受检测监督。

- **使用只接收 Origin 的 EMA teacher 作为共同参考。** Student 处理全部视图，teacher 仅处理同步变换后的 Origin，提供停止梯度的特征锚点；student 更新后以 \(\alpha=0.9998\) 更新 teacher。各风格视图分别对齐 Origin，形成星形结构，避免风格图之间互相传播生成伪影。需要注意，teacher 参数仍由接收全部视图训练的 student 做 EMA 得到。

- **同时约束场景与实例特征。** Global consistency 对各层 FPN 做 GAP、拼接和 L2 normalization，再以 cosine distance 对齐；GT-RoI consistency 在对应 GT 框上进行 RoIAlign、池化和归一化，每个场景最多使用 64 个实例。对应关系由场景、标注索引和类别确定，无需 proposals、伪标签或预测框匹配。

- **渐进加入一致性，保持标准推理图。** 总目标为
  \[
  \mathcal L=\mathcal L_{\mathrm{det}}+\rho(k)
  \left(0.10\mathcal L_{\mathrm{global}}+0.05\mathcal L_{\mathrm{roi}}\right).
  \]
  一致性权重在 2000 iterations 前为零，至 6000 iterations 线性升至完整权重。推理使用 EMA detector，检测头与单图计算结构不变。

### 实验

**设置与比较协议。** 主实验采用 ImageNet-pretrained ResNet-101-FPN Faster R-CNN，训练 20,000 iterations，global image batch size 为 16，使用包含 Origin 的 21-view bank，并在固定 20K endpoint 评估 EMA 模型。Cityscapes-source 基线引用已发表结果；RealDriveSim 基线在统一 split、detector、训练预算和评估代码下复现，源域为 6,000 scenes。

主要比较方法包括 CDSD、SHADE、SRCD、FACT、FSDR、MAD、GDD(R101)，以及 corruption 实验中的 FSCE、OA-Mix、OA-DG。

| 迁移任务 | 指标（%） | OAMSC | 主要对照 |
|---|---|---:|---|
| Cityscapes → BDD100K daytime-clear | mAP50 | 44.4 | GDD(R101)：46.3 |
| Cityscapes → Foggy Cityscapes | mAP50，七类，排除 train | 55.6 | GDD(R101)：52.3 |
| Cityscapes → Rainy Cityscapes | mAP50 | 63.1 | GDD(R101)：57.9 |
| RealDriveSim → Cityscapes | mAP50 | 43.5 | SHADE：42.2；GDD(R101)：41.7 |
| RealDriveSim → BDD100K daytime-all | mAP50 | 30.9 | SHADE：25.7；GDD(R101)：23.5 |

天气偏移下收益最明显：论文报告相对最强对照在 Foggy Cityscapes 和 Rainy Cityscapes 上分别提升 **3.2** 和 **5.2** points，Foggy 上领先七类中的六类。作者说明差值使用未四舍五入的结果，因此表中显示值的直接相减可能与正文差值不同。跨相机任务则仍落后 GDD，表明风格覆盖不能充分解决所有跨数据集偏移。

**Corruption robustness。** 主表采用 car-class AP50:95，覆盖 15 种 corruptions、五个 severities；不能与后续七类 mAP50 消融直接混用。

| 方法 | Clean | mPC | rPC |
|---|---:|---:|---:|
| FSCE | 43.1 | 21.0 | 48.7 |
| OA-Mix | 42.7 | 20.8 | 48.7 |
| OA-DG | 43.4 | 21.8 | 50.2 |
| GDD(R101) | 42.1 | 21.3 | 50.5 |
| OAMSC | 37.5 | 23.0 | 61.3 |

OAMSC 的绝对 mPC 最好，但 Clean 明显下降。由于 \(\mathrm{rPC}=100\times\mathrm{mPC}/\mathrm{Clean}\)，其较高 rPC 同时受到较低 Clean 分母的影响，应结合绝对性能判断。论文报告其在七种 corruptions 上领先；GDD 在 impulse noise、fog、brightness 和 contrast 上更强。

**One-stage 兼容性。** 在 BDD100K night-all 上，YOLOv8x 使用 Cityscapes 训练时，mAP50:95 从单视图的 10.2 提高到 21 views 的 12.3；使用 RealDriveSim 时，从 4.5 提高到 7.0。不过，该实验用固定的 BDD100K night validation subset 选择 checkpoint，与主实验固定 endpoint 的协议不同。

**核心消融。** 以下 mAP50 为 BDD、Fog、Rain 三个目标域的均值；Cityscapes-C rPC 基于七类 mAP50。

| 消融 | 配置 | mAP50 | Cityscapes-C rPC |
|---|---|---:|---:|
| L00 | 无 Global、无 GT-RoI consistency | 53.56 | 63.23 |
| L10 | 仅 Global consistency | 53.61 | 63.48 |
| L01 | 仅 GT-RoI consistency | 53.56 | 63.23 |
| L11 | 两种 consistency | 53.74 | 63.51 |
| M0 | Random；detection loss only | 50.02 | 59.36 |
| M1 | Grouped；detection loss only | 52.50 | 60.25 |
| M2 | Grouped；online Origin anchor | 52.35 | 60.22 |
| M3 | Grouped；EMA Origin anchor | 53.74 | 63.51 |

消融支持的结论是：

- **风格覆盖与分组训练是主要贡献。** 从 5 到 21 views，目标域平均 mAP50 提升 4.15 points，Fog、Rain、BDD 分别提升 7.39、3.91、1.16；Cityscapes-C mPC50 提升 0.85。每步仍采样四个视图，增加的是数据库覆盖。
- **分组本身很有效。** M1 相对 M0 提升 2.48 mAP50；online anchor 略有退化，EMA anchor 则明显更好。
- **层级一致性只是小幅细化。** L11 相对 L00 仅提升 0.18 mAP50 和 0.28 rPC，GT-RoI 单独启用没有可见收益；没有多次运行统计来判断这些小差异是否稳定。

### 局限与可追问点

1. **Source-only 协议存在局部例外。** YOLOv8x 兼容性实验使用 BDD100K night validation subset 选择 checkpoint。如果该 subset 来自目标域，就引入了目标域模型选择信息，应与严格未知目标域协议区分，并补充固定 endpoint 或 source-only selection 结果。

2. **消融存在需要澄清的配置差异。** L00 和 M1 都描述为 grouped、无一致性损失，但结果分别为 53.56 和 52.50 mAP50。L00 保留 EMA teacher，然而 teacher 不参与损失时，差异是否来自 EMA 推理、模型维护方式或其他设置，文中未说明。需要统一这些条件后，才能准确分离 grouping、EMA averaging 和 consistency 的贡献。

3. **生成质量依赖人工，缺少量化证据。** 文中未说明生成 prompt、重生成比例、人工工时、验收标准及小目标专项检查。对 Pixel Art、Building Blocks 等风格，值得检查目标边缘、遮挡关系和框内有效细节是否仍然可靠。

4. **稳健性存在性能取舍。** Corruption 主表中 Clean 为 37.5，低于各对照；跨相机迁移也未超过 GDD。应进一步验证源域性能损失、真实恶劣天气收益，以及纹理或颜色本身具有判别价值时的失败情况。

5. **机制证据以性能消融为主。** 文中未提供风格可预测性、跨风格特征距离变化或小目标表现等直接分析，也未提供具体失败案例。现有证据支持训练策略有效，但不足以充分证明模型确实减少了 style-sensitive shortcut learning。
