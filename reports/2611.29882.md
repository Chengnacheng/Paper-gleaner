### 一句话总结
论文提出无需反向传播的检测器权重编辑方法 IR-ODWSP，通过保函数逆重参数化与符合 set prediction 的闭式更新，在 26/26 个配置上取得小幅 MS COCO AP 提升，并改善部分未知域检测与无标签天气适应，但原生开销下的平均跨域收益较小，且部分延迟与单调性表述存在需核对之处。

### 问题与动机
论文研究的是：**如何直接编辑已训练检测器的权重，而不重新进行梯度训练，实现性能修复、跨域适应和部署定制。**它不是风格迁移或图像生成方法。

作者认为，将通用 Weight-Space Programming（WSP）直接用于目标检测有两个主要障碍：

- **重复框崩溃。**对于 one-to-one、NMS-free 检测器，把所有与 GT 的 IoU 足够高的候选都设为正样本，会让同一目标附近的多个框同时获得高分，而检测 AP 将额外框计为 FP。朴素 binary WSP 在 YOLO26-S/M 上分别造成 `-39.7` / `-43.7` AP。
- **收敛权重的 Euclidean stationary trap。**原生参数空间中的各向同性 ridge 更新，混合了背景、高能量粗尺度特征、外观统计与弱小目标信号；即便修正目标分配，收益仍可能接近零。

跨域动机是：部署后的检测器可能遭遇 Sketch、Weather 等偏移，但无法进行完整微调，因此希望通过前向统计和代数操作完成轻量修正。

### 方法要点
- **符合 set prediction 的闭式分类更新。**为每个 GT 选择 task-aligned top-1 winner；对重叠但未获胜的 sibling candidates 使用 ignore mask，而不是全部推为正样本或负样本。winner 的目标为软质量分数 \(q=\mathrm{IoU}^{\gamma}\)，再累计 Focal-curvature 加权的二阶统计并求解 ridge 方程。常规校准路径需要源域 GT，并非全流程无标签。

- **先扩展坐标，再编辑，最后折叠。**用精确保函数的 \(\mathcal E\) 将收敛层提升到可分离子空间，完成编辑后通过 \(\mathcal C\) 折叠回原生权重形状。核心解释是扩展—编辑—折叠相当于引入
  \[
  G_{\mathcal E}=(J_{\mathcal C}J_{\mathcal C}^{\top})^{-1}
  \]
  的各向异性正则化，而非“增加临时参数就自然变好”。该等价性有 Jacobian 满行秩等条件，不是 AP 改善保证。

- **分离外观、频率与特征协方差。**IR-AdaNorm 编辑归一化后的残差均值和方差，并可使用无标签目标域统计；IR-DCT 对卷积核进行 2D-DCT 分解，对 DC、中频和高频施加不同惩罚；IR-PCA 引入特征协方差及辅助头子空间，改变读出层的更新几何。

- **稳定类别与边界框校准。**对低样本类别的 bias 使用基于 COCO supercategories 的 James-Stein Empirical-Bayes shrinkage；IR-BoxAffine 在 winner 上拟合 \(4\times4\) 仿射变换，修正框坐标偏差。YOLO26 另使用非对称 collision gate，抑制辅助头引入的重复响应，并仅在孤立局部峰值上允许分数提升。

- **利用已有辅助分支，并区分单模型与跨模型模式。**单模型模式从训练时共训的 o2m、decoder 或 Group-DETR heads 提取子空间；跨模型模式可额外使用 Objects365 checkpoint，经 Orthogonal Procrustes 与 row-RMS matching 对齐，避免直接权重插值造成激活抵消。

- **按延迟预算选择部署图。**除纯折叠外，负预算通过闭式 ridge bridge 连接被绕过的子图；正预算采用 IR-ODWSP-Dyn 或 IR-ODWSP-SG 扩展推理。后两者包含额外分支、视图及定制 TensorRT kernels，应与纯权重折叠的收益分开理解。

### 实验
**数据与协议。**

- MS COCO 2017：`118,287` 张 train2017 图像，分为共 `115,287` 张的前向校准 folds 和严格分离的 `3,000` 张 holdout；在 `5,000` 张 val2017 上盲评。
- COCO-O：`6,782` 张图像、`26,624` 个框，包含 Cartoon、Handmake、Painting、Sketch、Tattoo、Weather；报告六域不加权 mean mAP。校准和选择阶段不接触 COCO-O。
- 检测器覆盖 YOLO26、EdgeCrafter（ECDet）和 RF-DETR，共 17 checkpoints、26 个单模型与跨模型配置。
- 另测试 composite Night+Fog+Noise 无标签目标流，以及人为注入 rank-1 weight spikes 后的零图像修复；这些实验不能直接等同于真实天气域泛化。

**对比基线。**包括 Official、Vanilla WSP、OD-WSP、Pure folded IR-ODWSP、带 gate 的 IR-ODWSP，以及有无 NMS 的 Official TTA；给定内容未报告与专门 single-domain generalization、风格增强检测方法的直接比较。

**主要结果：17-model 汇总。**

| 方法 / 设置 | MS COCO AP | COCO-O mAP | TensorRT \(B=1\) ms/img |
|---|---:|---:|---:|
| Official | 53.78 | 33.83 | 2.22 |
| IR-ODWSP，\(1.00\times\) | 53.84 | 33.88 | 2.25 |
| Contraction，\(\beta\leq-10\%\) | 51.62 | 33.48 | 1.78 |
| IR-ODWSP-Dyn，\(\beta\leq+10\%\) | 54.08 | 33.94 | 2.29 |
| IR-ODWSP-Auto，\(\beta\leq+100\%\) | 54.83 | 34.18 | 3.74 |
| Official TTA，NMS | 54.98 | 35.77 | 19.03 |
| IR-ODWSP+，Unconstrained | 55.91 | 35.44 | 208.8 |

### 与你研究的关系
**与你的跨域鲁棒性兴趣相关，但不是风格迁移式 single-domain generalization 的直接替代方案。**

1. **可作为单源泛化检测器的后处理模块。**只用 COCO 校准、完全不接触 COCO-O 的 Single-Model 路径，接近“源域校准后面向未知目标域”的需求；但必须排除额外 Objects365 prior，并明确基础模型预训练来源。使用无标签目标流的天气实验属于 adaptation，不应混入严格 DG 结果。

2. **适合借鉴“外观统计与语义更新解耦”。**IR-AdaNorm 和 IR-DCT 提供权重空间的外观、频率控制思路，可作为风格增强训练后的轻量校准，或与图像空间增强形成对照；论文没有验证二者是否互补。

3. **与小目标和框保持有关，但证据范围有限。**方法不生成风格化训练图像，因此不存在生成器直接扭曲图像和标注对应关系的问题；它也报告 \(\mathrm{AP}_{s}\) 和框校准。但这不等于保证小目标细节不受损，部分模型的 \(\mathrm{AP}_{s}\) 仍下降。

4. **对增强后的检测校准尤其有启发。**winner exclusivity、sibling-ignore 和质量感知目标值得迁移到你的实验设计中，用来检查风格增强是否改变候选竞争、分数排序及重复框，而不只看最终 mAP。

建议优先复现 **Single-Model、Pure folded、无目标域暴露** 三个条件，再分别评估加入 gate、风格增强以及目标域统计后的增益，避免将机制不同的收益混在一起。

### 局限与可追问点
- **收益小，统计可靠性不足。**原生开销下平均 COCO-O 收益仅 `+.050` mAP；文中未说明多次数据划分、置信区间或显著性检验。对于最小幅度的 AP 提升，需要检验其是否稳定超过评估与选择波动。

- **延迟“零开销”口径不一致。**纯折叠可以保持原生参数形状，但带 gate 的 \(1.00\times\) 行实际报告 `8.57` ms PyTorch、`2.25` ms TensorRT，而 Official 为 `8.07`、`2.22` ms。应区分“零新增参数”“原生图折叠”和“实际零延迟开销”。

- **严格单调性表述需要收窄。**Table S9 中 ecdet_o3652coco_m 从 `57.02` 降至 `57.01` AP，ecdet_o3652coco_x 从 `59.90` 降至 `59.88` AP；Table S7 的 OOD 结果也随预算出现下降。因此不能将 ID 平均趋势扩展为所有 checkpoint、所有域严格单调。

- **跨域失败确实存在。**RF-DETR-L 的 COCO-O mAP 从 `32.567` 降至 `32.442`；RF-DETR-M 的 IR-ODWSP+ 在 Tattoo 上从 `19.35` 降至 `17.71`。值得进一步按目标尺度、遮挡、纹理依赖和域类别定位损失来源。

- **机制证据不等于普遍鲁棒性证明。**各向异性 metric 的代数等价与随机坐标对照较清楚，但并未证明 PCA 高方差方向必然是跨域稳定语义方向；IR-DCT 单独使用出现负 OOD 增益，正好说明频段偏好可能依赖域。

- **真实天气与语义保持验证不足。**Night+Fog+Noise 的构造细节、目标流规模及适应顺序文中未说明；零图像修复针对注入的 rank-1 spikes，其对自然损坏的代表性也待验证。论文没有直接测量风格变化下边界框一致性、细粒度目标保持或极小目标漏检变化。

- **实验协议与实现仍需核查。**数据划分说明将 holdout 排除出校准，但运行时间说明又称对全部 `118,287` 张 train2017 累计统计，需要确认实际执行范围；另外，Table S4 将 RF-DETR-N 的 class_embed 编辑标为 IR-DCT，与正文 \(K\geq3\) 空间卷积核定义之间的对应关系文中未说明。应优先检查 split 文件、实际算子、完整超参数选择及消融脚本。
