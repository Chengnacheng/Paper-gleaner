### 一句话总结

论文提出 PG-FM（Prompt-Guided Feature Modulation），通过双曲空间中的逐样本退化表征，为冻结的 RGB–T 检测器生成融合层修正，在 FLIR-Aligned 和 KAIST 的模拟退化测试中分别将 mAP50 提升最多 20.8 和 19.9 个点，并在未经目标域优化的真实外部数据集上取得泛化收益，但不解决跨模态几何失配。

### 问题与动机

RGB–T 检测依靠 RGB 与 TIR 互补，但某一路信号发生噪声、模糊、低照度或传感器故障时，受损特征可能通过融合模块拖累整体检测。论文研究的核心问题是：**能否根据每个输入中两种模态的可靠性，直接调整检测器的融合行为，而不先恢复图像？**

作者指出三类不足：

- **先恢复再检测成本高，检测收益不稳定。** 图像恢复可能生成误导检测器的结构，而且感知质量改善不一定转化为检测性能改善。
- **Static PEFT 缺少输入适应性。** 固定的 FiLM 或 LoRA 修正主要适配训练退化分布，难以响应测试样本中不同模态、不同类型和强度的退化。
- **单一质量分数表达不足。** 退化接近干净状态时，各类型影响相近；退化加重后，其影响逐渐分化。因此，除了严重程度，还需要保留退化类型及空间分布信息。

其基本设定是空间对齐的 RGB–T 输入，主要处理信号质量变化。它与 single-domain generalization 有交集，但任务重点是**多模态退化鲁棒性和融合适应**，并非以风格变化为核心的单 RGB 域泛化。

### 方法要点

- **两阶段训练，检测器保持冻结。** Stage 1 为 RGB 和 TIR 分别训练 Prompt Generator；Stage 2 冻结两个 Prompt Generator 和原检测器，仅训练 Reliability Mining Module（RMM）。推理时直接从输入生成修正，不需要退化标签，也没有逐测试样本的梯度优化。

- **用空间特征与绝对信号统计共同诊断退化。** 多尺度特征被汇聚到 `14×14` 网格，共 `196` 个空间 token；Signal-Energy Token 引入通道均值、标准差及 GAP/GMP 描述，补充绝对能量信息。论文明确指出，单个 energy token 的 attention 实际承担全局残差条件化，而非空间选择。

- **在 Poincaré ball 中组织类型与严重程度。** 干净样本位于中心 clean trunk，退化类型由角方向区分，同类型严重程度由相对固定原型的测地距离排序。训练使用边界、类型分类、严重程度排序，以及同退化、不同场景之间的深度一致性约束。这个深度是学习得到的分支内坐标，仍可能受角度误差影响，并非跨类型统一标定的物理质量分数。

- **根据完整 prompt field 生成层级修正。** RMM 将两种模态的 prompt 映射回切空间，通过每个目标融合层的 query 与 prompt tokens 交互，为 ICAFusion 的 Q/K/V/O 投影生成 FiLM 或 LoRA 修正。相比直接给模态乘一个可靠性权重，它能够进行层与通道相关的细粒度调整。

- **用可靠性控制保持原模型的约束强度。** 两路输入可靠时，identity regularization 较强，使生成修正接近零；任一路退化加重时，约束放松。完整 prompt 决定修正内容，池化半径只控制正则强度；该设计不保证实际修正范数必然随退化单调增加。

- **通过受控退化学习跨场景可靠性。** RGB 使用 10 类、TIR 使用 9 类模拟退化。Stage 1 使用局部 mask，并构造不同场景但相同退化类型、强度和位置的训练对；Stage 2 使用全图退化并加入干净输入。模拟由传感器机理启发，但不是具体传感器的标定模型。

### 实验

**数据集与协议。** 受控实验采用 FLIR-Aligned 和 KAIST；Robust 设置独立、均匀采样两路模态的退化类型与强度。另评估未见退化、混合退化、独立实现的 Cross-sim.，以及仅在 FLIR-Aligned 训练后直接测试的 LYNRED-MDS、M3FD 和 ATR-UMOD。外部数据集不加入额外退化，也不进行目标域优化。

**对比方法。** 包括 Frozen ICAFusion、ProbEn、RSDet、TFDet、C2Former、YOLOv11-RGBT、UniRGB-IR；匹配条件的对照包括 Static PEFT、参数量匹配的 Zero-Prompt、Feature-RMM、替代 prompt 和直接可靠性 gating；恢复对照为 BioIR、PromptIR。论文将其他检测器作为背景比较，机制归因主要应看共享冻结检测器的匹配对照。

**主要受控结果：**

| 方法 | FLIR Clean mAP50 | FLIR Robust mAP50 | KAIST Clean mAP50 | KAIST Robust mAP50 | KAIST Robust LAMR-All ↓ |
|---|---:|---:|---:|---:|---:|
| Frozen ICAFusion | 82.8 | 40.5 | 76.6 | 34.7 | 43.5 |
| Static LoRA | 82.6 | 57.7 | 76.2 | 47.8 | 41.7 |
| Zero-Prompt LoRA | 82.4 | 59.8 | 75.4 | 51.7 | 39.4 |
| PG-FM LoRA | 83.2 | 61.3 | 77.4 | 54.6 | 35.8 |
| Static FiLM | 82.6 | 48.8 | 76.1 | 46.4 | 39.1 |
| Zero-Prompt FiLM | 82.6 | 48.9 | 76.3 | 46.2 | 39.5 |
| PG-FM FiLM | 82.8 | 57.7 | 76.6 | 51.7 | 37.1 |

PG-FM 在基本保持 Clean 性能的同时提高 Robust 性能。不过，**LoRA 的收益有相当部分来自适配本身**：参数量匹配的 Zero-Prompt 已达到 FLIR Robust `59.8`，PG-FM 为 `61.3`；FiLM 中 prompt 条件化的区分更明显，为 `48.9` 对 `57.7`。

**跨实现与真实外部数据泛化，指标均为 mAP50：**

| 方法 | Cross-sim. | LYNRED-IR | LYNRED-RGB | M3FD | ATR-UMOD |
|---|---:|---:|---:|---:|---:|
| Frozen ICAFusion | 42.6 | 32.2 | 29.2 | 31.4 | 19.0 |
| BioIR → ICAFusion | 41.4 | 32.1 | 28.4 | 29.2 | 19.2 |
| PromptIR → ICAFusion | 42.2 | 31.9 | 30.0 | 30.5 | 18.4 |
| Zero-Prompt | 48.1 | 33.3 | 32.2 | 32.3 | 27.0 |
| Feature-RMM | 43.3 | 31.8 | 29.5 | 32.0 | 19.2 |
| w/o L_pair | 52.5 | 34.1 | 33.5 | 34.4 | 33.2 |
| PG-FM | 55.2 | 35.9 | 34.4 | 37.0 | 35.7 |

LYNRED-IR 与 LYNRED-RGB 对应同一数据集的两种标注来源，不应视为两个独立采集域。PG-FM 在这些测试项上均最高，恢复方法则没有稳定改善原检测器。

**关键消融与机制证据：**

| FLIR FiLM 变体 | Clean mAP50 | Robust mAP50 |
|---|---:|---:|
| w/o Energy Token | 81.0 | 49.3 |
| Euclidean-polar | 80.8 | 52.9 |
| w/o L_pair | 82.9 | 55.2 |
| PG-ℓ₂：固定 identity regularization | 82.8 | 54.8 |
| PG-FM | 82.8 | 57.7 |

- Energy Token 对绝对信号诊断和干净性能都有作用；跨场景一致性约束同时改善受控鲁棒性与外部迁移。
- 固定正则弱于可靠性加权正则，支持按输入调整稳定性与适应能力的设计。
- 相同 `8 D` 下，Euclidean-polar 为 `52.9`，Poincaré 为 `57.7`；但 `32 D` Euclidean 达到 `57.2`，证据更支持双曲表示的紧凑性优势，而非其不可替代性。
- 直接 gating 的 Static scalar、Prompt scalar、Prompt spatial 分别为 `41.6`、`45.1`、`47.9`，低于 PG-FM 的 `57.7`，说明质量诊断之后仍需要更充分的融合修正。
- 修正按退化类型聚类的 silhouette 为 `0.68`，按场景为 `-0.21`。Shapley 分析也观察到输出贡献向干净模态转移，但其 prompt 与修正在各 coalition 间固定，属于给定适配策略下的归因。

**未见退化与失败边界。** 在 TIR Impulse Noise、RGB Zoom Blur、Barrel Distortion、Blackout-Blue 上，PG-FM 的 mAP50 分别为 `54.3`、`73.5`、`69.4`、`63.2`，均高于所列对照；混合退化也保持优势。几何错位则是明确失败边界：位移达到 `16` pixels 时，Frozen 与 PG-FM 分别只有 `9.6` 和 `10.7`，方法基本不能恢复跨模态对应关系。

**成本与稳定性。** Stage 1/2 分别训练 `25/50` epochs，使用 AdamW，计时设备为 NVIDIA RTX 5070 Ti。FiLM/LoRA 分别增加 `5.0/6.9 M` 可训练参数、`3.2/4.1%` GFLOPs 和 `10.5/12.3%` latency。匹配恢复实验中，PG-FM 增加 `5.46` GFLOPs / `2.25` ms，恢复方法为 `931–1079` GFLOPs / `327–345` ms。三个独立 seeds 的主要受控和未见退化结果标准差至多为 `0.7` mAP；完整结果位于未提供的补充材料。

### 与你研究的关系

**对跨域鲁棒性和泛化机制分析有较强参考价值；对风格增强型 single-domain generalization 的直接相关性有限。**

- **可借鉴“显式诊断偏移，再条件化检测器”的路线。** 外部迁移确实采用仅在 FLIR-Aligned 训练、不优化目标域的设置。对单源检测，可考虑将外观退化、风格变化的表征用于条件化 adapter，并通过严格匹配的对照检验收益是否超出普通增强和 Static PEFT；单 RGB 场景的有效性尚未验证。
- **跨场景一致性损失很契合域泛化目标。** 不同图像施加相同退化后，约束其质量表征接近，有助于减少场景内容对控制信号的干扰。它为构建内容相对独立的风格或退化描述提供了可操作思路。
- **对保留目标语义提供了替代方向。** PG-FM 在特征融合层适配，不经过生成式重建，避免了恢复模块额外引入结构的路径。但这不等于证明边界框、小目标细节得到保护：论文没有对应的尺度分组或定位误差分析。
- **消融设计值得复用。** 参数量匹配的 Zero-Prompt、直接特征条件化、类型/强度拆分、固定正则、独立退化实现和真实外部域测试，共同帮助区分容量收益、表征收益与泛化收益。
- **双模态互补是重要前提。** 不少测试保持另一模态干净，模型可以转向可靠模态；单 RGB 检测没有这一补偿来源，不能直接预期相同幅度的收益。

### 局限与可追问点

- **自然传感器故障验证仍不足。** 外部数据是自然采集的，但没有故障标签；代表性样本的 prompt 多处于中心或浅分支。因此，这些结果支持自然采集域迁移，却不足以单独证明自然严重故障识别能力。作者也将故障标注验证列为未来工作。
- **无法处理可靠性之外的几何问题。** 几何错位时 prompt 仍可能认为输入可靠，进而保持接近 identity。可追问是否需要将“信号质量”和“跨模态对应质量”分别建模。
- **小目标与定位质量没有专门证据。** 文中未说明 AP_small、按尺寸分组结果、框回归误差或小目标失败案例。`14×14` prompt 网格对局部细小损伤的敏感性值得验证。
- **两路同时严重失效的边界不清楚。** Robust 设置包含双路随机退化，但许多未见和混合测试保留干净互补模态；两路共同失去关键目标信息时，适配还能带来多少收益，文中未单独说明。
